# Project Brief

## Scope

macOS menu bar app that auto-records video calls and saves speaker-attributed transcripts as markdown files to a local inbox folder.

## Goals

- Zero-interaction recording – auto-detect calls, auto-record, auto-transcribe
- High-quality async transcription with speaker diarisation
- Transcripts in `~/call-transcripts/inbox/` for processing with Claude Code alongside prospect/customer context
